# Meteor Client

> **Minecraft Utility Mod** | Version v0.5.9 | Platform: Java Edition 1.21.4

## About

Meteor Client is an open-source utility mod for Minecraft targeting the latest versions. Highly popular for anarchy servers like 2b2t, offering powerful automation and griefing modules.

## Features

- KillAura
- AutoMine
- AutoCraft
- Nuker
- X-Ray
- ESP
- Tracers
- AutoFish
- EChestFarmer
- CrystalAura
- AnchorAura
- Scaffold
- Flight
- Baritone integration

## System Requirements

- Requires Fabric mod loader
- Designed for anarchy and permissive servers
- Active community and plugin system

## Installation

1. Download the latest version of **Meteor Client** from the link below
2. Run the installer and follow the on-screen instructions
3. Launch Minecraft and enjoy
